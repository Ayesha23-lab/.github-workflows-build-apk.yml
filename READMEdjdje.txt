AYESHA & SIMO — LOVE QUEST
==========================

This is a mobile-first installable web app (PWA), not yet a signed APK.
Features:
- 8 story chapters
- Unlockable levels
- Coins and hearts
- Heart-collector mini game
- Automatic local save using browser storage
- Animated character placeholders and glowing story scenes
- Offline caching after the first successful load

TRY IT:
1. Upload/extract this folder to a static web host that supports HTTPS.
2. Open the hosted URL in Chrome on Android.
3. Chrome menu (⋮) > Install app or Add to Home screen.
4. Open it from the new home-screen icon.

SAVE DATA:
Progress is saved on the same device/browser. Clearing browser data or changing devices may erase it. This version does not have cloud sync or accounts.

IMPORTANT:
- Coins/hearts are game points, not real money.
- This package is a prototype. It has not been tested or published on Google Play.
- To create a Play Store APK/AAB, wrap the PWA with a trusted Android wrapper or rebuild it in Android Studio, then test, sign and publish it. Get a parent/guardian's help with developer accounts and payments.
- Character art in this prototype uses animated emoji/CSS placeholders; the generated poster is a visual concept, not imported as character sprites.
